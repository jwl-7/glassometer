# glassometer

### glassmorphism speedtacometer for Assetto Corsa

<img width="586" height="599" alt="image" src="https://github.com/user-attachments/assets/32a9c2f7-4793-4734-bd68-47270116c85d" />

## Features
- SPEED in `mph` or `kmh`
- RPM and BOOST gauge
- GEAR number
- `[RIGHT-CLICK]` to pin
- scales to any size with perfect resolution as no images are used
- looks cool

## Installation
1. Download [latest release](https://github.com/jwl-7/glassometer/releases)
2. Drag `.zip` to `CM` (Content Manager)
