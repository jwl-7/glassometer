# glassometer

### glassmorphism speedtacometer for Assetto Corsa

<img width="300" alt="glassometer-ss" src="https://github.com/user-attachments/assets/98c22a41-28cd-4433-abf6-70165487d998" />

## Features
- SPEED in `mph` or `kmh`
- RPM and BOOST gauge
- GEAR number
- `[RIGHT-CLICK]` to pin
- scales to any size with perfect resolution as no images are used
- looks cool

## Installation
1. Download [latest release](https://github.com/jwl-7/glassometer/releases)
2. Drag `.zip` to `CM` (Content Manager)
